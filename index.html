Privacy & backups

This standalone file has no analytics, advertising, account, or cloud connection. Your habit data is saved in this browser on this device using local storage.

Important: if you open this file from different locations or browsers, they may not share the same storage. Do not clear browser website data unless you have exported a backup. Local storage is not encrypted.

Private by design: the app itself makes no network requests. Browser/OS backup behavior is controlled by your device settings. This file cannot prevent someone with access to your unlocked phone from seeing the tracker.
